# Funban

Планировщик на неделю для команды из пяти человек: цель спринта, входящие со скринами, бэклог со своими критериями, комментарии.

```bash
npm install
npm run dev
```

Откройте http://localhost:5173. Состояние пишется в `data/state.json` — одна доска на всех, кто открыл этот адрес в сети.

## Постановка задач из Claude и Codex

После деплоя production-сервер поднимет удалённый MCP endpoint `https://funban.future-db.ru/mcp`. Он умеет:

- показывать участников, недели и критерии оценки;
- искать задачи перед созданием дубля;
- создавать и редактировать задачи;
- назначать участника по имени;
- ставить двусторонние связи между задачами.

MCP не умеет удалять задачи, закрывать спринт или перемешивать роли. Каждая запись имеет `requestId`, поэтому повторная отправка одного запроса не создаёт дубль. Изменения пишутся атомарно, а журнал операций хранится рядом с файлом состояния.

### Сервер

Нужен один общий токен команды — персональные токены не используются. Сам токен в репозиторий не добавляется:

```bash
export FUNBAN_MCP_TOKEN='общий-токен-команды'
export FUNBAN_PUBLIC_URL='https://funban.future-db.ru/'
export FUNBAN_TIME_ZONE='Europe/Moscow'
npm run build
npm start
```

Если reverse proxy меняет HTTP-заголовок `Host` на внутреннее имя, добавьте его через `FUNBAN_ALLOWED_HOSTS` (несколько имён разделяются запятыми). Публичный домен и localhost разрешаются автоматически.

Если сайт целиком закрыт HTTP Basic Auth на reverse proxy, для `/mcp` нужно отключить Basic Auth и оставить проверку Bearer-токена приложением. Иначе Claude и Codex не смогут передать оба способа авторизации в одном заголовке.

### Codex

```bash
export FUNBAN_MCP_TOKEN='общий-токен-команды'
codex mcp add funban \
  --url https://funban.future-db.ru/mcp \
  --bearer-token-env-var FUNBAN_MCP_TOKEN
```

### Claude Code

```bash
export FUNBAN_MCP_TOKEN='общий-токен-команды'
claude mcp add --transport http --scope user funban \
  https://funban.future-db.ru/mcp \
  --header "Authorization: Bearer $FUNBAN_MCP_TOKEN"
```

### Один раз в начале личного чата

Напишите, например:

> В Funban по умолчанию создавай задачи на Лилю. Если я явно назову другого участника — назначай ему.

После этого можно писать обычным языком: «Добавь в бэклог задачу про новый онбординг, свяжи с задачей про реквизиты и оцени по критериям». Имя, явно указанное в такой постановке, всегда имеет приоритет над исполнителем по умолчанию. Общий токен только даёт доступ к доске и сам по себе не определяет автора или исполнителя.
